# Habitub

> A minimalist, activity grid based habit tracker.

Habitub is designed to make habit tracking simple, visual, and motivating. Track your daily habits, build streaks, and see your consistency through activity grids and calendars.

## Highlights

- Minimalist activity-grid-based habit tracking
- Streak-based gamified habit tracking
- Separate activity grid for each habit
- Color and emoji coding for habits
- Historical habit tracking and backfilling
- Calendar-based progress tracking
- Light and dark themes
- Mobile-friendly interface
